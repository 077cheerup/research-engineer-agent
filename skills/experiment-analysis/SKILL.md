# 实验结果解释规范

## 适用任务

解释 `analyze_experiment` 返回的最小化优化实验结果，比较算法的最终性能、跨 Seed 离散程度和平均收敛趋势。本 Skill 不计算统计量，不运行 Benchmark。

## 分析步骤

1. 以工具返回的函数、优化方向、数据路径和 SHA256 确认本次数据。
2. 查看每个 Seed 最后 FE 的结果，比较最终 Mean、Median，再描述 Sample Std。
3. 查看完整平均收敛表，只在已记录的采样点比较水平与趋势。
4. 说明数据性质和检验边界，输出有数值依据的结论。完整统计和证据由程序传递，不要重新计算或抄写整表。

## 最终性能解释规范

- 最小化问题的最终 Mean 较低，表示本次重复运行的平均最终 fitness 较低。
- Median 描述最终结果的中间位置，可与 Mean 一起报告。没有分布证据时，不据两者差异断言异常值或分布形状。
- Best、Worst 只是已观测样本的极值，不代表算法的理论上下界或泛化保证。
- 不把模拟样本表现推广到真实 CEC2013 或其他函数、预算。

## 稳定性解释规范

- `sample_std` 使用 `ddof=1`，衡量各 Seed 的最终结果离散程度，不是所有 FE 数值的波动。
- 推荐：“本次样本中，B 的最终结果标准差较小，跨 Seed 离散程度较低。”
- 较小 Std 不等于“统计显著更稳定”，也不说明连续轨迹更平滑。

## 收敛趋势解释规范

- 平均收敛曲线是在相同 FE 上跨 Seed 求均值。描述“在这些采样点均值较低”，不声称采样点之间全程领先。
- 某 FE 的 fitness 水平较低，不能直接证明下降速度更快；速度涉及区间变化和起点条件。
- 不从每点较低推断差距持续扩大；需要逐点差距证据，而当前工具没有计算这种派生指标。
- 不编造达到阈值的时间、收敛速率、AUC、提升百分比、差值、p 值、置信区间或其他工具未计算的统计量。

## 显著性检验边界

工具没有执行统计显著性检验。明确声明“未进行显著性检验”，不得用“显著低于”“显著更优”“统计显著更稳定”修饰当前差异。Mean、Median 或 Std 的大小关系都不能代替检验。

## 模拟数据声明要求

当前输入为模拟数据，只用于演示 Agent 分析流程，不是真实 CEC2013 Benchmark 实验。最后一个 FE 是演示预算，不能冒充正式实验预算；不编造正式实验环境、日期或复现结论。

## 常见错误与推荐表述

| 错误表述 | 推荐表述 |
| --- | --- |
| B 的均值显著低于 A，因此显著更优。 | 本次模拟数据中 B 的最终均值较低；未进行显著性检验。 |
| B 的 Std 较小，因此统计显著更稳定。 | 本次样本中 B 的最终结果离散程度较低，不能断言统计显著差异。 |
| 单个 FE 上 B 的均值较低，因此下降更快。 | 在该 FE 采样点 B 的均值较低；不能据单点水平判断下降速度。 |
| 所有采样点均值更低，所以全程领先且差距持续扩大。 | 在已记录的采样点均值较低；不推断连续路径或差距变化。 |
| 提升了某个百分比，或者 p 小于某个值。 | 仅引用工具实际提供的统计量，不增加未经计算的数字。 |
